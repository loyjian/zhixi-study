# 知习 我的练习本

免登录的个人练习网站，801道题。顺序及随机练习、错题本、收藏、进度恢复、备份导入导出和手机布局。记录保存在访问者浏览器中，不上传服务器。37道存疑题保留说明，不自动判分。

本地运行：在本目录执行 `python -m http.server 8765 --directory dist --bind 127.0.0.1`，访问 http://127.0.0.1:8765 。请通过HTTP访问，不要直接双击index.html。

发布到GitHub：将本目录的内容放到目标仓库根目录，在仓库 Settings → Pages 将 Source 设置为 GitHub Actions，推送 main 后由工作流部署 dist。

网址的域名和路径决定本地数据所属站点。切换正式网址、换设备、换浏览器之前，先导出备份，再在目标网址导入。清除浏览器网站数据将清除记录；同一浏览器的多个标签页不建议同时作答。同一浏览器共享同一份记录。

本地存储包含每题累计次数、错题状态和收藏；详细作答明细保留最近10000条，累计统计不受截断影响。自动保存失败会提示导出备份。离线缓存需要先成功在线加载，正式部署须通过HTTPS。题库答案为参考答案，未经学校平台判分核验。

不包含账号、数据库、分析追踪或外部字体依赖。以后更新静态资源时请增加 sw.js 的缓存版本号，避免离线缓存长期使用旧资源。
